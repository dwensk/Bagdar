# Bagdar

Сервис для студентов Казахстана: калькулятор стоимости перевода между вузами, каталог вузов с ценами, правила перевода и документы для поступления. Проект команды BAgdar по курсу «IT-стартапы», ЮКУ им. М. Ауэзова.

Сайт: https://dwensk.github.io/Bagdar/

## Команда

| Участник | Часть | Файлы |
|---|---|---|
| Участник 1 | База сайта: калькулятор, каталог, регистрация, оплата, админка | `index.html`, `assets/css/style.css`, `assets/js/app.js`, `config.js`, `data.js`, `i18n.js`, `store.js` |
| Участник 2 | История расчётов | `assets/js/history.js` |
| Участник 3 | Логотип-компас | `assets/img/logo.svg`, `.brand-mark` в `style.css` |
| Участник 4 | Сравнение вузов | `assets/js/compare.js` |

## Как сделан проект

Код написан с помощью ИИ-ассистента Claude (Anthropic). Команда отвечала за идею, данные о вузах, проверку и защиту проекта.

## Устройство

- Статический сайт без сервера, размещён на GitHub Pages.
- Данные пользователей хранятся в `localStorage` браузера (демо-режим). Для настоящих оплат нужен сервер, например Supabase.
- Цвета и шрифт задаются в `assets/css/style.css`, блок `:root`. Цена подписки — в `assets/js/config.js`.
